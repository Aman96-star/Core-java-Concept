## 1. What This Video Is

This is a short **announcement/trailer**, not a teaching episode. There is no code, no theory, and no interview content in it — so there's nothing to take "deep notes" on in the usual sense. Treat it as the **table of contents** for the season.

## 2. Why Season 2 Exists

Season 1 of Namaste JavaScript covered *JS engine internals* — execution context, hoisting, scope chain, closures, the event loop, etc. Season 2 shifts focus to the topic every interviewer loves to dig into: **Asynchronous JavaScript**, plus a few standalone but equally interview-heavy topics.

## 3. Season 2 Roadmap (what the rest of these notes cover)

| Ep | Title | Core Topic |
|----|-------|------------|
| 01 | Callback Hell | Callbacks, callback hell, inversion of control |
| 02 | Promises | What a Promise is, Promise states, `.then()` |
| 03 | Creating a Promise, Chaining & Error Handling | `new Promise()`, `resolve`/`reject`, `.then().catch()` chains |
| 04 | async await | `async` functions, `await`, execution suspension, try/catch |
| 05 | Promise APIs | `Promise.all`, `allSettled`, `race`, `any` |
| 06 | `this` keyword | `this` in global/function/method/arrow-function/DOM contexts |
| Bonus | Top 9 JS topics before React | Prerequisite roadmap before starting React |

## 4. How to Use These Notes

Each episode has its own file, following the same structure:
`Theory → Comparison Table → Code → Diagram → Extra Interview Q&A → Quick Reference`.

Study them **in order** — Ep 01 → 02 → 03 build directly on each other (callbacks → promises → promise chaining), Ep 04 (async/await) is "sugar" on top of Ep 02–03, Ep 05 is an extension of promises for multiple parallel calls, and Ep 06 (`this`) is a standalone but classic interview topic.
